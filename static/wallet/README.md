# Boutons Wallet officiels

`google-wallet-fr.svg` est le bouton français inchangé de Google, issu de l'archive officielle : https://developers.google.com/static/wallet/download-assets/add-to-wallet-svg.zip

Directives Google : https://developers.google.com/wallet/retail/loyalty-cards/resources/brand-guidelines

Pour Apple, le propriétaire du compte doit accepter les conditions de diffusion de l'illustration et télécharger le badge officiel depuis https://developer.apple.com/wallet/add-to-apple-wallet-guidelines/index.html . Placer ensuite le SVG français inchangé sous `static/wallet/apple-wallet-fr.svg`. Tant que cet asset n'est pas fourni, l'interface affiche une action texte de téléchargement et ne reproduit pas un faux badge Apple.
